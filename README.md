# 羅占盤（rasenban）

9つの占術を統合し、命盤・相性・16タイプ診断を生成する占いWebアプリ。

公開URL: https://rasenban.com/

## 主な機能

- 生年月日・出生時刻・出生地による命盤生成
- 9占術（西洋占星術・四柱推命・紫微斗数・算命学・数秘術・九星気学・マヤ暦・宿曜・インド占星術）による多面的分析
  - 宿曜：三九の秘法の早見表（27宿との関係・近/中/遠距離）、今日の宿曜運勢
  - 九星気学：本命星・月命星（立春・節入り基準）、傾斜宮、今年と来年の吉方位
  - 数秘術：ライフパス、人生の4つの時期（ピナクルとチャレンジ）
  - 算命学：高尾式の人体星図（節入りからの日数で蔵干を選ぶ）
- 今日の羅占盤：日ごとの運を持つ5つの占術（四柱推命・九星気学の日盤・宿曜・マヤ暦・数秘術）が、今日（と明日）を「動く／整える／慎重」のどれに振り分けたか
- 16タイプ判定
- 自分／相性の2モード
- AI鑑定用プロンプトの生成（自分のAIに貼って鑑定文を得る方式）
- 鑑定結果の貼り付け・表示
- タロット占い（`tarot/`）

## 構成

- `index.html` — メイン。命盤計算・9占術描画・タイプ判定・プロンプト生成・鑑定貼り付けを含む
- `type-judge.js` — 16タイプ判定ロジック
- `synthesis.js` — 総合鑑定の冒頭のまとめ。9占術のうち何種類が同じ傾向を示したか（4つの軸・強み3つ・今の時期）を出す
- `ephemeris-data.js` / `celestial-sphere.js` — 天体位置データ（画面の表示を止めないよう裏で読む）と天球描画
- `lunar-data.js` — 旧暦の月表（宿曜・紫微斗数で使う）。`generate_lunar.py` で作り直す
- `16typecard/web/`・`icons/*.webp`・`Zodiac/*.webp` — 画面で使う軽い画像（元のPNG・SVGは素材として残している）
- `tarot/` — タロット占い

## 計算の検算

計算を変えたら必ず回す。アプリの関数は使わず、暦の定義と Swiss Ephemeris から独立に計算して突き合わせる（要 `pyswisseph`・`playwright`）。

```bash
python3 _check.py           # 基準の12人で全項目（四柱・九星・マヤ・宿曜・紫微・天体・ASC/ハウス）
python3 _check.py --sweep   # 1950〜2030年の毎日で一致率
```

## タイプ別ページ（SNS用）

`type/<英名>.html`（16枚）はSNSで共有されたときにそのタイプの絵と説明が出るページ。開いた人は `index.html#type=<英名>`（16タイプ図鑑）へ移る。タイプの文（type-judge.js の TYPES）を直したら作り直す。

```bash
python3 generate_type_pages.py   # type/*.html と type/og/*.jpg（1200×630）を作る
```

## ローカル起動

```bash
python3 -m http.server
```

ブラウザで http://localhost:8000/ を開く。
